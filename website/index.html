Questions

Which sites work?

Droplet uses the open-source yt-dlp engine, which supports YouTube and many other sites. Some sites only work when you are signed in; Droplet can use your browser's login for one download if you allow it. Sites change often, so support can come and go. Try your favourite sites with the free downloads before you buy.

Is the Terminal install safe?

The install line runs a short, readable script from this website (open it). It downloads Droplet, checks that the file is exactly the one published here, copies it to Applications and opens it. Many Mac tools install this way. Downloads from a web browser need an extra approval in System Settings for apps sold outside the App Store; the Terminal install doesn't.

Where are my videos saved?

In your Downloads folder. You can choose another folder in Droplet's settings (the gear icon).

How do I update or uninstall Droplet?

To update, run the install line again. To uninstall, quit Droplet from its menu, then drag Droplet from Applications to the Trash. Before you move to a new Mac, use Deactivate this Mac in Droplet's license settings so your key works on the new one.
