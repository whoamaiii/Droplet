Questions

Straight answers about sites, the free trial, installing and privacy.

Which sites work?

Droplet uses the open-source yt-dlp engine, which supports many video sites, including YouTube. Some sites only work when you are signed in; Droplet can use your browser’s login for one download if you allow it. Sites change often, so support can come and go. Try the sites you care about with the free downloads first.

What counts as one of the free downloads?

Only a new video that is fully saved and passes Droplet’s check of the file. Failed or cancelled downloads don’t count. You don’t need an account.

What do I get if I choose US$0?

The same full license as at {{price}}: unlimited downloads, with a license key sent by email after checkout. You paste the key into Droplet’s settings once.

How is a US$0 license different from the free trial?

The trial needs no checkout and ends after three saved videos. A launch license comes from checkout, at any price you choose up to {{price}}, and has no download limit.

What does the Terminal install do?

It runs a short, readable script from this website. The script downloads Droplet, checks that the file matches the SHA‑256 fingerprint published with this release, copies it to Applications and opens it. Many Mac tools install this way.

A copy of Droplet downloaded with a web browser needs a one-time approval in System Settings, because Droplet is sold directly instead of through the App Store. The Terminal install doesn’t need it.

Where are my videos saved?

In your Downloads folder. You can choose another folder in Droplet’s settings (the gear icon, or ⌘ Command + ,). macOS may ask once for permission to save there.

How do I update, move or uninstall Droplet?

To update, run the install line again. To uninstall, quit Droplet from its window, then drag it from Applications to the Trash.

Before you move to a new Mac, use Deactivate this Mac in Droplet’s license settings so your key works on the new one.

What if Droplet doesn’t work for me?

Write to {{support_text}} within {{refund_days}} days of your purchase and you get a full refund.

Does Droplet collect my data?

No. Droplet has no analytics, tracking or ads. Video links and cookies go only to the video site. Checking a license sends only the license key. The privacy policy has the details.
